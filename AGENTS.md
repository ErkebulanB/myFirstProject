# AGENTS.md

Инструкции для будущего AI/Codex-агента в этом репозитории:

1. Не хранить API-ключи и секреты во frontend.
2. Не удалять HCI-блоки (WCAG, Fitts’s Law, GOMS, Usability Testing, чатбот).
3. Сохранять и улучшать доступность:
   - labels,
   - keyboard navigation,
   - focus state,
   - aria-live,
   - контраст.
4. После изменений проверять запуск проекта (`npm run dev`) или минимум сборку (`npm run build`).
5. Не усложнять проект без необходимости: это учебный demo-проект.
6. Код должен быть простым, читаемым и понятным для защиты в университете.
