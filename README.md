# Student Planner (HCI Full-Stack Demo)

Учебный full-stack проект для дисциплины «Человеко-компьютерное взаимодействие» (HCI). Приложение помогает студенту управлять задачами, а также демонстрирует элементы доступности, usability и работу LLM-чатбота через backend API.

## 1) Краткое описание

Проект состоит из:
- **Frontend (React + Vite)** — интерфейс планировщика;
- **Backend (Node.js + Express)** — REST API для задач и endpoint для чата;
- **SQLite** — хранение задач в файле `backend/database.sqlite`;
- **OpenAI API** — генерация ответов чатбота через `POST /api/chat` (с fallback-режимом, если ключ не задан).

## 2) Стек технологий

- Frontend: React, Vite, CSS
- Backend: Node.js, Express, dotenv
- Database: SQLite (`better-sqlite3`)
- LLM: OpenAI Node SDK

## 3) Функции проекта

- CRUD задач:
  - `GET /api/tasks`
  - `POST /api/tasks`
  - `PATCH /api/tasks/:id`
  - `DELETE /api/tasks/:id`
- Фильтры задач: все / активные / выполненные
- Статистика: всего / выполнено / активно
- LLM-чатбот через backend endpoint `POST /api/chat`
- Fallback-ответы чатбота, если OpenAI API ключ не указан

## 4) HCI-элементы

### Nielsen heuristics
- Видимость статуса системы: сообщения об успехе/ошибках и loading-state.
- Контроль и свобода пользователя: возможность удалить/изменить статус задачи.
- Предотвращение ошибок: базовая валидация формы и подтверждение удаления.
- Согласованность и стандарты: единые стили элементов и понятные подписи.

### WCAG / доступность
- Skip-link «Перейти к основному содержимому».
- Явные `label` для всех полей формы.
- Контрастные цвета и заметный `focus-visible`.
- `aria-live` для статусов формы, списка задач и чата.
- Адаптивность под мобильные экраны.

### Fitts’s Law
- Крупные кликабельные кнопки (высота минимум ~44px).
- Действия расположены рядом с контекстом (например, удаление возле нужной задачи).

### GOMS
- В интерфейсе есть таблица Goal / Operators / Methods / Selection rules для типовых действий.

### Usability testing
- Таймер сценария с кнопками «Начать тест» / «Завершить тест».
- При старте теста фокус автоматически переходит к полю названия задачи.

### Personas / целевая аудитория
- Студенты бакалавриата и магистратуры, которым нужно быстро планировать учёбу.
- Пользователи с разным уровнем цифровой грамотности.

## 6) Инструкция запуска

### Backend

```bash
cd backend
npm install
cp .env.example .env
npm run dev
```

Backend запускается на `http://localhost:3001`.

### Frontend

```bash
cd frontend
npm install
npm run dev
```

Frontend запускается на `http://localhost:5173`.

## 7) Как подключить OpenAI API

1. Откройте файл `backend/.env`.
2. Вставьте ключ:

```env
OPENAI_API_KEY=ваш_ключ
OPENAI_MODEL=gpt-4.1-mini
```

3. Перезапустите backend (`npm run dev`).

## 8) Если API-ключа нет

Проект всё равно работает:
- управление задачами работает полностью;
- чатбот отвечает в demo/fallback режиме полезным шаблонным планом.
